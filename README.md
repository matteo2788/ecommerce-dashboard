# E-Commerce Store case study

Portfolio case study for Matteo Conforti's independent online sneaker store, December 2023 through June 2024. Built with React and Vite. Business platform: WordPress and WooCommerce.

## Figures

All business figures are approximate historical estimates: 120 pairs, $149 average selling price, $95 average product cost. The visuals derive $17,880 sales, $11,400 product cost, and $6,480 remaining after product cost. The remaining amount excludes shipping, payment processing, refunds, advertising, and all other expenses. It is not net profit. No monthly distribution, traffic, conversion, or acquisition data is available or displayed.

## Development

Run `npm ci`, then `npm run dev`. Run `npm run build` for the production bundle and `npm run preview` to inspect it. No backend, authentication, or external data services are required. Typography uses a local system font stack, without external font requests.

The existing Vercel project `ecommerce-dashboard` deploys the `main` branch. Production: https://ecommerce-dashboard-rho-blue.vercel.app/
